# Reconstructing the R environment

The statistical pipeline was executed with **R 4.6.1**, **Bioconductor 3.23** and native Apple Silicon packages. Package versions are fixed before restoration; no command here upgrades R or writes to a global R library.

| Package | Exact version |
|---|---|
| edgeR | 4.10.7 |
| limma | 3.68.5 |
| statmod | 1.5.2 |
| locfit | 1.5-9.12 |
| lattice | 0.22-9 |
| jsonlite | 2.0.0 |
| BiocManager | 1.30.27 |
| BiocVersion | 3.23.1 |

`renv.lock` was generated from the installed packages by renv 1.3.1, with R and Bioconductor versions recorded. This repository does not auto-activate renv or edit `.Rprofile`. `R-packages.lock.tsv` complements the manager lock with exact official artifact URLs, package versions, native-binary/source distinctions and measured SHA256 hashes. The tested restoration entry point is `restore_R.R`; a separate `renv::restore()` was not tested.

## Restore

Install R 4.6.1 separately, then run from the repository root:

```bash
Rscript --vanilla environment/restore_R.R
Rscript --vanilla tests/test_statistics.R
```

The restorer installs into `environment/R-library` and retains archives in `environment/package-cache`. It verifies SHA256 before installation and exact versions afterward. Existing packages at the locked version are reused; a conflicting version causes an error instead of being overwritten. An absent archive is downloaded from the URL recorded in the lock. No latest-version substitution is attempted.

On an ARM64 Mac, native R 4.6 binaries are selected where available. The exact `lattice` version is supplied by the official CRAN source archive and was compiled successfully with Apple clang on the execution host. A command-line C compiler is therefore required even for the native Mac restoration. All installation work is limited to two workers.

On other platforms, or with `--source`, exact source archives are selected. A suitable R build toolchain, including C/C++ and Fortran support, is required. The complete source installation on Linux, Windows or Intel macOS has **not** been tested. The R interpreter, system compiler and system libraries are not installed by this script.

## Isolated verification

After restoring the Python environment described below, a new project-local R library can be restored and the distribution checked without changing the primary R library. Run from the project root:

```bash
Rscript --vanilla environment/restore_R.R --library=environment/R-library-clean
AD_ASTRO_R_LIBRARY=environment/R-library-clean \
R_LIBS_USER=environment/R-library-clean R_LIBS_SITE= \
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 VECLIB_MAXIMUM_THREADS=2 \
bash check.sh
```

`bash check.sh` is the supported verification route for a fresh distribution after both environments are restored; it uses synthetic fixtures and included saved results without raw-data retrieval or study refitting. The legacy `Rscript --vanilla tests/test_statistics.R --empirical` route additionally reads `results/tables/primary_fit.rds`, which is intentionally omitted from this distribution and must first be generated by the full analysis workflow. Existing result tables alone do not satisfy that prerequisite. Running that R script without `--empirical` exercises only its synthetic tests. The `AD_ASTRO_R_LIBRARY` variable is process-local and selects the requested library; the default remains `environment/R-library`.

The original reconstruction was executed in a fresh local library using cached verified archives: eight packages were installed, all six directly or transitively loaded statistical packages resolved to that clean library, and the 12 synthetic check categories plus 13 empirical consistency assertions passed. The system R base/recommended runtime remains shared; this is not an operating-system container or an independent external reproduction of the biological study.

To prohibit all downloads once the archive cache is populated:

```bash
Rscript --vanilla environment/restore_R.R --library=environment/R-library-clean --offline
```

## Maintenance and provenance

- Keep package caches, installed libraries and clean test libraries outside Git. Preserve them locally; restoration does not delete caches or libraries.
- `R-packages.lock.tsv` records the original package build metadata and exact source/binary artifacts. Source builds need not have byte-identical compiled libraries across platforms.
- `results/audit/R_sessionInfo.txt` records the original analysis runtime. Input data provenance is recorded separately in `data/input_manifest.json`.
- Changing R, Bioconductor or a package version requires a deliberate new environment and rerunning scientific consistency checks. Do not silently edit only one of the two R lockfiles.
- Remote archives may become unavailable. Keeping the checksummed project-local cache preserves the verified artifacts; a lockfile alone does not guarantee indefinite mirror availability.
- Python packages are pinned in `environment/requirements.lock.txt`. The execution interpreter was Python 3.12.14 on ARM64 macOS. Restore from the repository root with `python3.12 -m venv .venv`, then `uv pip sync --python .venv/bin/python --require-hashes --cache-dir environment/uv-cache environment/requirements.lock.txt`. The complete pipeline and data retrieval are documented in the main README.

The manager lock was produced without project activation using `renv::snapshot(lockfile=NULL, packages=...)` followed by `renv::lockfile_write()`. Network-based latest-package validation was not used to change the pinned stack; archive checks, actual restoration and functional tests supplied the verification evidence.

## Final document typography

The final report and scientific figures use existing local Times New Roman and Arial TrueType fonts. On the tested Mac these are in `/System/Library/Fonts/Supplemental`. `scripts/typography.py` checks the required filenames and fails clearly if they are absent. `AD_ASTRO_FONT_DIR` can point to another local directory containing those files. The full-run entry point checks these files only when rendering is requested. `--analysis-only` skips presentation imports, font checks, figure exports and report rebuilding while retaining the statistical stages and their checks. The pipeline does not fetch fonts or modify system font settings. Measured font checksums are in `document_fonts.json`; font files themselves are not distributed. Rendering on other operating systems or with other font versions remains untested.

The earlier writing revision reused a restored Python environment and clean R library without additional installations. That historical statement does not describe the Phase 1 environment restoration. `bash run.sh --revision-only` requires the raw inputs and primary fit needed by the original sensitivity module; it is not a fresh-checkout shortcut.

## Check a distribution without raw data

After restoring both libraries, run `bash check.sh` from the repository root. This entry point exercises the existing small synthetic suites and exported-result checks without downloading raw data or reading the omitted primary fit. The result verifier writes its record under ignored `.build/validation/`. A full analysis rebuild remains `bash run.sh --download`.

## Phase 1 validation from included count tables

The Phase 1 runtime uses native ARM64 Python 3.12.16, R 4.6.1 and the existing locked package versions. The original analysis used Python 3.12.14; this interpreter patch difference is recorded rather than silently replacing the historical runtime. Restoration remains local to `.venv/` and `environment/R-library/`, with verified archives retained in project caches. See [the validation guide](../VALIDATION.md) for the retained execution evidence and supported checks.

After restoring the two environments, use:

```bash
bash run.sh --targeted-validation --analysis-only
```

This path refits the full-donor diagnosis model from the included pseudobulk counts, compares it with the stored primary results and fits 18 donor omissions using the same retained genes and canonical symbol mapping. It uses the frozen mapped Hallmark membership already included in the repository. It also computes donor-level expression diagnostics. Omit `--analysis-only` to rebuild figures and documents after the numerical stages. No raw count HDF5, original cell metadata, GMT retrieval or omitted `primary_fit.rds` is required. This scope must not be described as a fresh reconstruction from the original single-cell data.

The entry point limits numerical threads to two and runs donor omissions sequentially. Keep an unchanged snapshot when comparing outputs. The final verification command remains `bash check.sh`; it checks small fixtures and saved outputs without refitting the study. Runtime restoration, model refitting, static checks and document rendering are recorded as separate operations.
